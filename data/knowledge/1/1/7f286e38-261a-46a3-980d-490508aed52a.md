# **一、openslide**

你可以用下面的命令测试 openslide 是否安装和可用：

```cmd
python -c "import openslide; print(openslide.__version__); slide = openslide.OpenSlide"
```

如果没有报错，说明 openslide-python 和底层 DLL 都没问题。

---

## 如果遇到 DLL 错误（常见报错如 WinError 126/127）

### 1. 下载 openslide-win64 二进制包  
[官方下载地址](https://openslide.org/download/) 或 [GitHub镜像](https://github.com/openslide/openslide-winbuild/releases)

### 2. 解压后，将以下 DLL 文件夹路径**加入系统环境变量 PATH**  
比如：  
```
D:\tools\openslide-win64-20230414\bin
```
或者把所有 DLL（如 libopenslide-0.dll、libjpeg.dll、libtiff.dll 等）复制到你的 Python 环境的 `Scripts` 目录或你的项目根目录。

### 3. 重新打开命令行窗口，激活环境，再次测试

---

## 其他注意事项

- 有时还需要安装 [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist?view=msvc-170)
- 路径一定要加到**系统**环境变量（不是用户变量），并重启命令行窗口
